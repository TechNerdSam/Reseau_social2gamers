## 🏗️ Architecture & Fonctionnalités (Le Moteur)

Ce projet repose sur une **architecture API-First** légère, séparant la logique de traitement (`/api`) de l'affichage (`/templates`).

### ⚙️ Core Features

  * **Flux d'Activité Temps Réel 📰 :** Système de posts dynamique via `api/get_posts.php`.
  * **Interactions Sociales ❤️ :** Système de likes asynchrone (`api/like_post.php`) pour un engagement instantané.
  * **Messagerie Privée 💬 :** Infrastructure de chat interne (`messages.php`, `api/get_messages.php`).
  * **Notifications Push 🔔 :** Alertes utilisateurs centralisées (`api/get_notifications.php`).
  * **Gestion de Profil 👤 :** Édition et personnalisation de l'identité gamer (`profil.php`, `api/get_user_data.php`).

### 🛠️ Stack Technique

  * **Backend :** PHP 8.x (Logique procédurale optimisée).
  * **Database :** MySQL/MariaDB (Structure relationnelle optimisée pour les réseaux sociaux).
  * **Frontend :** HTML5, CSS3 (`style.css`), JavaScript Vanilla (`script.js`) - Zéro dépendance lourde.

## 🚀 Protocole de Déploiement

Transformez ce code en réseau social actif en moins de 10 minutes.

### 1\. Prérequis Système

  * Serveur Web (Apache/Nginx)
  * PHP 7.4+
  * MySQL

### 2\. Initialisation

1.  Clonez le dépôt dans votre répertoire serveur :
    ```bash
    git clone https://github.com/TechNerdSam/reseau_social2gamers.git
    ```
2.  Importez la structure de base de données (SQL) dans votre gestionnaire (phpMyAdmin/Adminer).
3.  Configurez les accès base de données dans : `Réseaux_social_Gameur/config.php` (ou fichier de connexion équivalent).

### 3\. Lancement

Accédez à `http://localhost/reseau_social2gamers/Réseaux_social_Gameur/index.php`.
Le système d'authentification (`handle_inscription.php`) prend le relais pour l'onboarding des nouveaux utilisateurs.
